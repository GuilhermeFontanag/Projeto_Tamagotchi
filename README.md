### Projeto Tamagoshi
 Um projeto criado em sala de aula acerca de um bichinho virtual.

 ### Sobre o Projeto
 O propósito do projeto é criar um bichinho virtual, que ira possuir "nome", "fome", "energia" e "humor".
  Podendo manipular a "fome", "energia" e "nome" a partir dos Setters e visualizar seus status com o uso do Getters. Entretanto o a caracteristica "humor" do bichinho virtual, que dependera da fome e energia.

   ### Como executar
   Para executar esse projeto é necessario instalado em sua maquina:  
    * JDK25
    * VScode ou IDE que suporte java
